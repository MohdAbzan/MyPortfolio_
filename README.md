# Mohammed Abzan — Portfolio

Personal portfolio website for Mohammed Abzan (Administration & Customer Service Professional, dnata / Emirates Group).

**Live site:** https://mohdabzan.github.io/MyPortfolio_/

## Stack
- React (Create React App + CRACO)
- Tailwind CSS
- Framer Motion

## Contact form
The contact form submits directly to [Web3Forms](https://web3forms.com) — no backend server or database required. The site is fully static and deploys to GitHub Pages automatically via GitHub Actions on every push to `main`.

## Local development
```bash
cd frontend
yarn install
yarn start
```

## Build
```bash
cd frontend
yarn build
```
